Fig. 01 — Signal flow

No API? No problem.

REV 0.1

Studio One has no public remote API, so FenderStudioProMCP drives it through four push-based paths — with a MIDI→command control surface as the reliable backbone.

224built-in commands, by name — verified end-to-end
4control paths: MIDI→cmd · MCU · menus · macros
0public API required — all push-based
01 · backbone

MIDI → command

A control surface maps MIDI CCs to Studio One <Command>s. Send a CC → the command fires. Reliable, no Accessibility.

02

MCU MIDI

Faders, pan, mute, solo, transport via the built-in Mackie Control Universal surface.

03

Menu automation

Clicks menus & sends shortcuts via System Events; verifies each via the Edit▸Undo label.

04

Macro generation

Writes .studioonemacro files for command sequences with no shortcut.

Scope. The 224 mapped commands are Studio One built-ins. User macros don't dispatch from a control surface — they need a keyboard/Command-Bar trigger, tracked on the roadmap.
Fig. 02 — Assembly

Four steps

macOS
01

Install

pip install -e ".[dev]" in the repo (Python 3.10+).

02

Install the control surface

Copy studio-one-devices/StudioOneMCPPads/ into Studio One's User Devices, add it in External Devices, set Receive From = StudioOneMCP.

03

Run the server

studio-pro-mcp --port-name StudioOneMCP — opens the virtual port Studio One binds to.

04

Connect your MCP client

Point Claude Desktop (or any MCP client) at it and drive your DAW by name.
